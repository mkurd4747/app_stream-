## Monitoring

The API provides the following monitoring endpoints:

- `/health` checks whether the API is running.
- `/ready` checks whether the database is accessible.
- `/metrics` returns Prometheus-compatible request metrics.

Every response includes an `X-Request-ID` header. If the caller supplies an
`X-Request-ID`, the API preserves it. Otherwise, the API generates a unique ID.

The Docker image checks `/health` automatically to determine whether the
container is healthy.
## Database migrations

This project uses Alembic to version and apply database schema changes.

Show the current database revision:

    python -m alembic current

Show the complete migration history:

    python -m alembic history

Apply all pending migrations:

    python -m alembic upgrade head

Reverse the most recent migration:

    python -m alembic downgrade -1

Check whether the SQLModel definitions contain changes that are missing a
migration:

    python -m alembic check

Create a migration after changing a database model:

    python -m alembic revision --autogenerate -m "describe the change"

Always review an autogenerated migration before applying it. Database files,
environment files, credentials, and secrets must not be committed.
